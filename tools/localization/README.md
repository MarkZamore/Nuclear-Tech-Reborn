# Русский квестбук и стартовая памятка

Выберите русский язык Minecraft в меню игры. В Better Questing Unofficial переводятся названия и описания заданий и веток. У The One Probe переведены название стартового предмета и памятка, которая открывается по ПКМ. Приседание с ПКМ по-прежнему открывает штатное меню настройки датчика.

Java 8 bootstrap в lanminecraft загружает словарь из config/lanminecraft/nuclear-book-ru.tsv. Клиентская обработка Better Questing сопоставляет оригинальные названия и описания с их точным текстом. Идентификаторы, условия, награды, связи между квестами, авторская разбивка и сохранения мира берутся из исходной сборки. Срабатывают и переводы для ранее созданных миров, если в их базе есть сопоставленный авторский текст. Для другого языка и для неизвестного текста используется вывод мода. Памятка The One Probe использует исходные режимы и кнопки. Словарь подставляет надписи в их штатных местах.

## Обновление от автора

1. Подготовьте новый авторский ZIP и upstream locks по основному README. Рецепт в tools/overlay.json закрепляет все источники Better Questing, включая общий DefaultQuests.json и раздельные файлы, а также точные JAR обоих модов.
2. Если квест изменился, добавьте ручной перевод нового текста в один из файлов ru-*.jsonl. Сохраните предыдущую строку для миров с прежним содержанием. ID состоит из первых 16 шестнадцатеричных символов SHA‑256 оригинального текста в UTF‑8. В каждой строке есть исходный текст en и перевод ru. Сохраняйте коды §, ссылки, числа и тип переносов строк.
3. При смене версии мода проверьте методы QuestTranslation, GuiNote и ProbeNote по актуальным JAR и при необходимости обновите код bootstrap, исходные строки памятки и пути JAR в build_dictionary.py.
4. Пересоберите и проверьте словарь после обновления locks. Генератор повторно использует переводы для прежних текстов, включает исторические строки в словарь и сообщает ID новых строк без перевода. Поле bookLocalization обновляется из актуального авторского архива. Словарь включается в обычную упаковку по основному README.

~~~powershell
python -B tools/localization/build_dictionary.py $authorZip
python -B tools/localization/build_dictionary.py $authorZip --verify
~~~

Для выпуска только локализации используйте tools/localization/stage_books_release.py с путём к LANMinecraft, новым выходным каталогом, полным SHA коммита и SHA‑256 свежего публичного манифеста. Скрипт переиспользует прежние проверенные активы. Публикуйте новые архивы перед заменой pack-manifest.json. Прежние архивы сохраняйте доступными для текущих клиентов.

## Проверка

Штатные проверки упаковки и генератор сверяют авторские входы, полный охват текстов по обеим формам хранения, форматирование и попадание словаря в манифест. Код в qa используется только в изолированной проверке Forge 14.23.5.2859 и Java 8. Он проверяет переключение языка у нативного клиента, отображение примера из Better Questing и название и текст стартовой памятки. В поставку проверочный код не входит.
