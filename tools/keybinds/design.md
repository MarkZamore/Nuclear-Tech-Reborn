# Пресет управления Nuclear Tech Reborn

Таблица закрепляет 33 штатных назначения Minecraft 1.12.2 и просмотренные назначения модов Forge 14.23.5.2859. Коды соответствуют LWJGL 2. Forge читает сочетания в виде «код:модификатор». В файле хранятся только строки для кнопки «Пресет управления». Лаунчер применяет их после подтверждения игрока.

| Группа | Основные назначения |
|---|---|
| Minecraft | WASD, прыжок, приседание, бег, кнопки мыши, инвентарь, чат, панель и творческие сохранения сохраняют штатные клавиши |
| Квесты и добыча | N открывает Better Questing, клавиша ё / grave активирует FTB Ultimine. У Better Questing и BQUTweaker разные клавиши возврата |
| JEI и карта | R и U показывают рецепты и применения в инвентаре. J открывает JourneyMap, B создаёт метку, точка с запятой переключает миникарту. Стрелки двигают полноэкранную карту |
| Advanced Rocketry | F9 переключает реактивный ранец. Num 4/6 поворачивают, Num 8/2 поднимают и опускают аппарат, Num 5 переключает RCS, Num 0 открывает интерфейс |
| NTM CE | Стрелки и Enter управляют краном в мире, R перезаряжает, Num Enter запускает рывок. Дополнительное действие оружия использует Mouse 4, третье действие использует Num +. Отдельная клавиша HUD ранца оставлена свободной |
| Applied Energistics 2 | Для пяти беспроводных терминалов предусмотрены Shift+I, Shift+Backslash, Shift+0, Shift+Num 3 и Shift+F12 |
| Голос | V открывает меню, G открывает группу, M отключает микрофон. Клавиши «говорить» и «шептать» сохраняют штатное пустое назначение |

## Проверка и публикация

Проверка выполнена вне игры по опубликованным JAR, авторским конфигурациям, Forge GameSettings и обработчикам событий. В авторском архиве отсутствует options.txt. Scan.java выводит места конструирования KeyBinding, регистрации и обращения к LWJGL, затем назначения и контексты сверяются по инструкциям класса и конфигам. reviewed-jars.json закрепляет JAR с найденными регистрациями. Advanced Rocketry формирует часть ID после локализации, поэтому строки с альтернативными именами в bindings.tsv описывают одно действие. Они проверяются как одна запись.

Проверка учитывает раздельные экраны, например JEI и полноэкранную JourneyMap. У двух сочетаний с общим основным кодом и разными модификаторами Forge выбирает активный модификатор. Удержание Shift или Ctrl сохраняет штатное приседание или бег. Проверка охватывает описанный набор назначений и контекстов. Снимок реестра из игры, модовые назначения, формируемые только при нестандартной конфигурации, и применение пресета в игре не проверялись. Жёстко заданные действия модов за пределами KeyBinding не управляются пресетом.

При изменении JAR пересмотрите назначения и контексты. Для воспроизведения сканирования Java 8 с собранным в стенде Scan.class принимает каталог mods. Для следующих правок обновите таблицу, сгенерируйте файл и обновите SHA‑256 в tools/overlay.json.

~~~powershell
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py --mods $verifiedMods
python -B tools/keybinds/stage_preset_release.py $launcherSource $candidate --revision $commit --base-sha256 $publishedManifestSha256
~~~

Сборка публикуется вручную через существующий GitHub pack-latest. Сначала загрузите новый архив launcher и новый архив карточки. Сверьте размеры и SHA‑256 через GitHub, затем замените pack-manifest.json. Оставьте старые архивы доступными для клиентов с предыдущим манифестом. Проверьте свежий манифест и извлеките файл из указанного ZIP для сверки SHA‑256. Обычное восстановление с полного авторского lock также включает файл через tools/overlay.json.
